Thrust-driven vehicles

Thrust-driven vehicles move only through the forces of their engines, such as a lander with a main engine and two side engines. The agent decides which engine to fire at each moment to steer the vehicle where it should go.

Principles

Key quantities
vertical velocity \(v_y\), angular velocity \(\omega\), horizontal velocity \(v_x\)
Approach speed
\(v^*(e,a)=\operatorname{sgn}(e)\min\big(\sqrt{2a|e|},\,|e|/\tau\big)\): fast when far, slowing down on arrival
Target tilt
\(\tilde\theta=\theta_l\operatorname{clip}\big((v_x-v^*(-x',a_x))/0.5,\,-1,\,1\big)\), the lean the remaining \(v_x\) still needs
PrincipleWhenReference
Return to the heightalways\(v_y\to v^*(h_{\text{target}}-h',\,a_y)\)
Return to the centrealways\(v_x\to v^*(-x',\,a_x)\)
Lean as neededalways\(\omega\to\operatorname{sgn}(\tilde\theta-\theta')\sqrt{2a_\omega|\tilde\theta-\theta'|}\)

Primes mark the next state with the engines off; \(h\) is the height above the pad and \(h_{\text{target}}\) the target height, 7 m.

Principles

Key quantities
vertical velocity \(v_z\), angular velocities \(\omega_x,\omega_y\)
Approach speed
\(v^*(e,a)=\operatorname{sgn}(e)\min\big(\sqrt{2a|e|},\,|e|/\tau\big)\)
Target tilt
\(\tilde n=\sin\theta_l\operatorname{clip}\big((v^*(\rho',a_h)\,u-v_h)/v_c\big)\), the lean the remaining horizontal velocity still needs
PrincipleWhenReference
Climb to the targetalways\(v_z\to v^*(z_{\text{target}}-z',\,a_z)\)
Lean as neededalways\((\omega_y,-\omega_x)\to\frac{\tilde n-n'}{|\tilde n-n'|}\sqrt{2a_\omega|\tilde n-n'|}\)

Primes mark the next state without action; \(n\) is the horizontal part of the thrust axis, \(\rho\) the horizontal distance to the target and \(u\) its direction.
